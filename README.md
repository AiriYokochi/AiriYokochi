# Airi Yokochi

HRI / Kansei & affective engineering / awareness. ROS, Raspberry Pi Mouse, Arduino, M5Stack.
人と一緒に長く暮らすロボット（記憶・世話・一緒に育つこと）を、小さく作って、実際に暮らして、確かめています。

I build small robots that live with people for a long time — memory, care, growing together — and test them by actually living with them.
